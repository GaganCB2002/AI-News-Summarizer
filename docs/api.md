# API Documentation

The AI News Summarizer exposes a RESTful API powered by FastAPI. 
All endpoints (except `/health` and `/`) are grouped under the `/api/v1` prefix.

## Authentication
Most endpoints require authentication via JWT. Pass the token in the `Authorization` header:
`Authorization: Bearer <access_token>`

## Endpoints

### Auth (`/api/v1/auth`)
- `POST /register`: Register a new user.
- `POST /login`: Authenticate and receive a JWT.
- `POST /refresh`: Refresh an expired JWT.
- `GET /me`: Get current user details.
- `PUT /me`: Update current user details.

### News (`/api/v1/news`)
- `GET /`: List paginated news articles, filterable by category, language, etc.
- `GET /search`: Search for articles via query `q`.
- `GET /{article_id}`: Retrieve a specific article.
- `POST /fetch`: Trigger fetching of new articles from external sources.
- `GET /{article_id}/summary`: Retrieve the existing summary for an article.
- `POST /{article_id}/summarize`: Trigger AI summarization for an article.

### Summaries (`/api/v1/summaries`)
- `GET /`: List all summaries generated by the user.
- `GET /{summary_id}`: Retrieve a specific summary.
- `DELETE /{summary_id}`: Delete a summary.

### Preferences (`/api/v1/preferences`)
- `GET /`: Retrieve the current user's preferences.
- `PUT /`: Update the user's preferences (e.g., favorite categories, summary length).

*Note: For the full interactive OpenAPI schema, run the server and navigate to `http://localhost:8000/docs`.*
